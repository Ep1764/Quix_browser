Click a game to load it in a tab. Every frame gets the permissions a game actually needs — pointer lock, fullscreen, gamepad — plus the keyboard focus most embeds forget. Badges record what happened on this device; they are never a guess.

Favourites

Why some games say “can’t embed”. A site can send an X-Frame-Options or Content-Security-Policy: frame-ancestors header telling the browser to refuse being put in a frame. That refusal is enforced by the browser itself, before any of this page’s JavaScript runs — so no amount of code here can override it, and the browser never reports back which sites did it. That is why a badge stays untried until you actually play: Quix reports what happened rather than guessing. For sites that refuse, Open in a real tab is one click and always works. About

Quix Browser is a single static HTML page that loads other sites in an <iframe> and gives those frames the permissions a browser game actually needs — pointer lock, fullscreen, gamepad and keyboard focus. It has no server and no backend; it can only show you sites your browser was already able to reach.
